How the whole product gets tested

A systematic QA program across 128 routes, 67 tools and 18 API modules — functional, performance, throttle, load, accessibility, cross-browser, security and visual regression, automated in CI. Every promise we make gets a test that fails loudly if it stops being true, and every issue raised becomes a permanent guard.

02

How "every single thing" is guaranteed

Cross-cutting ×

13 checks run against every route: load, no console errors, SEO, indexability, responsive 375–1440, both themes, a11y/axe, perf budget, security headers, 404/wrong-file, service worker.

×

Archetype matrix +

Each route maps to one of 9 families (client tool, server tool, micro-utility, AI, editor, auth, landing, legal, standalone app). The family's full scenario matrix runs with the route's real fixture.

+

Per-route specifics +

The unique & edge cases for that one route — the 27 MB compress benchmark, Tally debit-sign, redaction burn, find-&-replace across pages.

+

Regression seeds

Every issue ever raised has a test that fails on the old behaviour. A route isn't "covered" until all four columns are green.

03

Non-functional testing

Performance

Lighthouse budgets in CI

Score, LCP, CLS, TBT and first-load JS budgeted per archetype. A regression fails the build. SEO = 100, a11y ≥ 95.

Throttle

Slow 3G + CPU 4×

A dedicated project throttles network & CPU on home, compress, editor and an AI tool — catches the cold first-drop class of issue.

Load / stress

Big files & bursts

100 MB compress, 1 GB rotate (~56s), 500-page detect; backend burst asserts 429s, quotas, degrade-don't-fail, no 5xx.

Accessibility

axe on every archetype

Zero serious/critical violations, keyboard-only journeys, focus-visible, reduced-motion honoured, contrast on both themes.

Security

Headers, authz, sanitize

CSP/HSTS present, no secrets in bundle, gated tools 402 by direct URL, input sanitisation, auth-brute-force rate limit.

Visual regression

Snapshot diffs

Per-archetype screenshots in light + dark at two widths, diffed on every PR — guards the premium-toolbar standard & layout.
