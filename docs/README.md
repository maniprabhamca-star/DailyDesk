## Model in one line
Every in-browser tool is **free & unlimited forever** (they run on your device and cost us nothing). Only the few server-processed tools are metered: **Office conversions = 3 free/day → Pro unlimited**; OCR + AI = Pro. The Pro tier's moat is a set of features rivals structurally can't copy — **on-device batch, redaction certificate, saved workflows, encrypted File Vault** (flagships), plus self-destruct shares, certificate of completion, Bates numbering, brand kit, and an offline PWA.

- **[designs/forms-finder-phase3.md](designs/forms-finder-phase3.md)** — ⭐⭐ **Phase 3 of the forms plan — the one that converts, and the only one a competitor structurally cannot copy.** A reader arrives with a *task*, not a form number, so 13 task pages compose the **30 US forms we already verify** into ordered sets — **zero new forms, zero new verification load** — each row printing the thing nobody else prints: **who fills it in, and where it goes** (the W-9 goes to the payer, the W-4 stays with payroll, **WH-381 is the employer's notice to you**). Needs the verified index **and** the fill engine **and** on-device chaining; pdfFiller has one of the three. Carries the constraint that shapes it all — **a task page never says "you need"**, there is no `required` in the vocabulary, `notCovered` is mandatory and above the fold, and the words "you must" fail the build — plus the trap the weekly job cannot see: **a set goes stale while every number on it still verifies `drifts=0`**, hence **two clocks (`CHECKED_ON` vs `reviewedOn`), never merged**. The Pro half is the **packet** (details typed once, written into every form, finished through the existing Saved Workflows runner), which settles **D3**; decided in the doc rather than asked: **the shared details are never persisted** — "typed once" means once per packet, because a stored name + address + SSN is the exact artefact the product exists not to create. Honest limit stated: **USCIS PDFs are encrypted, pdf-lib reads 0 fields**, so the packet pre-fills IRS forms and says "overlay" on the rest. 3 ships (~10 h / ~12 h / ~6 h); open F1–F2.
